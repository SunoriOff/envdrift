# Changelog

## 0.1.0

- Initial release.
- `envdrift check` and `envdrift fix` commands.
- Detects undocumented, stale, missing and extra variables.
- Detects secrets in `.env.example` and `.env` tracked by git.
- Supports Python, JS/TS, Go, Ruby, PHP, Rust, Java/Kotlin and docker-compose.
- Text and JSON output, `--strict` mode for CI.
